tg-event-analytics

Підрахунок міжетнічних інцидентів у РФ за даними Telegram — як дедуплікованих подій, а не постів. Вимоги та статус реалізації.
готово реалізовано й перевірено в роботі частково / валідується todo ще нема

Архітектура пайплайну

collect TeleZip /Find (усі репости, unique=false) → Post enrich метадані каналів (кеш) + LLM-регіон каналу → Channel precluster content_hash + fuzzy текст (вікно) БЕЗ AI → Post.dedup_group classify LLM на ОДНОМУ представнику групи → копія на копії → is_relevant, поля dedup ковзний мікро-батч: по днях, вікно, пари — LLM → Event (стрімінг) aggregate розбивки по місяцях/регіонах/типах/тегах → ResearchRun.stats
Довідники (теги, тип, регіон) канонізуються LLM — без дублікатів за сенсом.
